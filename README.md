# Cybersecurity Home Lab

## About This Project
This repository documents my university and self-directed cybersecurity laboratory exercises. I am developing practical knowledge of network security, vulnerability assessment and Linux-based security tools.

## Tools and Technologies
- Kali Linux
- VMware
- Metasploitable2
- Nmap
- Linux command line
- TCP/IP networking

## Practical Experience
### Virtual Lab Setup
Worked with Kali Linux and Metasploitable2 virtual machines, configured virtual network adapters and used snapshots to manage lab environments.

### Network Reconnaissance
Used Nmap for host discovery, port scanning and service-version detection. Examined network scan results to identify active systems and exposed services.

### Security Assessment Learning
Explored deliberately vulnerable systems to develop an understanding of common security weaknesses and safe testing practices.

## Skills Developed

- Virtualisation
- Security documentation
- Analytical problem-solving
