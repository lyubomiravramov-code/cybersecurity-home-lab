# Responsible use and disclosure

This repository is intended for learning and professional development. Tests must only be conducted against lab machines, systems I control or systems whose owners have given explicit permission.

## Do not upload

- Passwords, private keys, `.env` files, cookies or API tokens.
- Non-public network diagrams identifying other people or devices.
- Personal names, MAC addresses, external addresses or third-party data.
- Screenshots exposing browser profiles, accounts, file paths with personal details or unredacted network information.
- Reports from systems outside the agreed lab scope.

Before publishing a scan log or image, redact sensitive information and verify that all targets are authorised. Keep deliberate vulnerable targets isolated.

If a potential vulnerability is identified on a third-party system, do not publish identifying details. Follow the owner's responsible disclosure process.
