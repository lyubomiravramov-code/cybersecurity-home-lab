# Screenshots and evidence

No original screenshots are included in the initial package.

To add an image:

1. Capture a screenshot from the **authorised virtual lab**.
2. Crop out credentials, home network information, user profile names, MAC addresses and other private details.
3. Verify that the image does not contain information about third parties.
4. Save it with a descriptive name, for example `nmap-lab-sanitised.png`.
5. Reference it in the relevant lab report, with a caption and date.

Avoid claiming that sample commands or hypothetical results are observed evidence.
